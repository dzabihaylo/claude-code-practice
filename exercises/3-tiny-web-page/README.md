# Exercise 3: A tiny web page

`index.html` is a very small web page. Ask Claude to open it in your browser.

It has two problems:

1. The heading says "Helo, world".
2. The list says it has three favorite things, but only shows two.

Ask Claude to fix both on a new branch, open the page again to check, then open a pull request.

**Bonus:** ask Claude to change the background color to one you like, and explain which line it changed.

**Done when** the page looks right and your pull request is merged.
