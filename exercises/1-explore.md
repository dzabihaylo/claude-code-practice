# Exercise 1: Explore

Nothing to change yet. Just ask Claude questions about this repo. Try these:

1. "What files are in this repo, and what is each one for?"
2. "What is the README for?"
3. "What does CLAUDE.md do, and did you read it?"
4. "What is a commit? Show me the commits in this repo."
5. "What is the difference between the copy on my computer and the copy on GitHub?"

**Done when** you can explain in your own words what a repo is.
