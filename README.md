# Claude Code Practice

A small, safe practice repo for people trying [Claude Code](https://claude.com/claude-code) for the first time.

Nothing here is real work. It exists so you can learn how a repo, a branch and a pull request fit together, with Claude doing the typing.

## How to use it

1. On GitHub, click **Use this template**, then **Create a new repository**. Name it `claude-code-practice` and make it **Private**. This gives you your own copy, so nothing you do affects anyone else.
2. Open Claude Code and ask it to clone your new repo to your computer.
3. Work through the exercises in order. For each one, ask Claude for help in plain English.

## Exercises

| # | Exercise | What you learn |
| --- | --- | --- |
| 1 | [Explore](exercises/1-explore.md) | What a repo is, and how Claude reads one |
| 2 | [Fix the typos](exercises/2-fix-the-typos.md) | Branches, commits and pull requests |
| 3 | [A tiny web page](exercises/3-tiny-web-page/) | Changing something and seeing the result |

## What's in this repo

- `README.md`: this page. Most repos have one, and it's the first thing to read.
- `CLAUDE.md`: house rules that Claude reads at the start of every session in this folder.
- `exercises/`: the practice material.
