# House rules for this repo

This is a practice repo for someone using Claude Code for the first time.

- Explain what you are about to do, in plain language, before you do it.
- Avoid jargon. When a technical word is unavoidable, explain it in one sentence.
- Never change the `main` branch directly. Make a branch, commit there, and open a pull request.
- Keep changes small, so each pull request is easy to read.
- If the person seems unsure, offer to explain, and let them say they already know it.
